- [ ] 三个探索点可交互，激活状态两端一致，流送往返后不重复。
- [ ] 合作模式测试攻击不伤害玩家。

- [ ] 普通客户端离开不影响主机；主机退出按预期结束会话。
- [ ] 日志无持续网络错误、ensure 或崩溃。
