# Demo 验收清单

记录引擎/构建版本、测试机器、日期和日志位置。每项标记通过/失败及证据，不把仅编译通过视为玩法通过。

## PIE 两玩家（Listen Server）

- [ ] 两端分别控制自己的角色，移动/跳跃/朝向同步，无重复输入。
- [ ] 三个探索点可交互，激活状态两端一致，流送往返后不重复。
- [ ] 合作模式测试攻击不伤害玩家。
- [ ] PvP 测试攻击在服务器扣血，两端生命一致。
- [ ] 死亡后约 2 秒由服务器复活，输入、ASC、相机和 HUD 恢复。
- [ ] 迟加入获得正确模式和地图；断线后可以重新加入。
- [ ] 普通客户端离开不影响主机；主机退出按预期结束会话。
- [ ] 日志无持续网络错误、ensure 或崩溃。

## Win64 Development 打包版双机 LAN

- [ ] 主机选择合作，第二台电脑输入 LAN IP 成功加入，无需互联网。
- [ ] 双方可移动、探索并看到一致的探索点状态。
- [ ] 主机选择 PvP 后可完成攻击、伤害、死亡和复活闭环。
- [ ] 连续运行 15–30 分钟，无崩溃、持续 ensure 或明显状态失同步。
- [ ] 记录 FPS、内存、网络异常和流送情况；未验证项目明确标注。

## 非本次承诺

互联网/NAT、主机迁移、专用服务器、大规模玩家、正式地图性能、弱网、四人和跨平台需要另行验证。
